Ringkasan Pilot & Rekomendasi — Klasifikasi ASD vs TD (ABIDE I, sMRI T1w + fenotipik)¶

Ini hasil PILOT pada sampel ±20 % dataset (200 dari 1.002 subjek), bukan hasil akhir. Sampel diambil hanya dari 853 subjek development (stratifikasi site × label × fold, seed 42); 149 subjek test held-out tidak disentuh. Tujuan pilot: memastikan pipeline benar & bebas kebocoran, memilih kandidat model, lalu mengunci konfigurasi sebelum dijalankan pada data penuh.

Semua angka dibaca langsung dari hasil runner/notebook 06 (report/); tidak ada model yang dilatih di notebook ini. Metrik: BA = balanced accuracy, F1m = F1 macro, AUC = ROC-AUC; pooled out-of-fold test 5 fold, 95 % CI bootstrap 2000×. Batas acak: BA = 0,5 dan AUC = 0,5.

def num(s):   # "0.584 [0.512, 0.652]" -> (0.584, 0.512, 0.652)
    a = [float(x) for x in re.findall(r"-?\d+\.\d+", str(s))]
    return tuple(a[:3]) if len(a) >= 3 else (np.nan,) * 3
def f2(x): return f"{x:.2f}".replace(".", ",")
def ci(e, k): v = num(M.at[e, f"{k} [95% CI]"]); return f"{f2(v[0])} [{f2(v[1])}–{f2(v[2])}]"

2. Dataset yang digunakan¶

ABIDE I (Autism Brain Imaging Data Exchange I): data multi-site dari 17 institusi (20 site setelah pemecahan per protokol), berisi citra MRI struktural T1-weighted dan data fenotipik (diagnosis, usia, jenis kelamin, IQ, dll.). Label: DX_GROUP 1 = ASD (autism spectrum disorder), 2 = TD (typically developing). Tabel pertama menunjukkan jumlah subjek di tiap tahap seleksi; tabel kedua demografi per partisi, termasuk sampel pilot ±20 % yang dipakai pada laporan ini.
